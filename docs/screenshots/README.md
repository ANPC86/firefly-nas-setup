# Screenshots

Captured 2026-09-03 from a **demo user** on the reference install (Firefly III 6.6.6), seeded with the synthetic fixture by [`tools/seed_demo.py`](../../tools/seed_demo.py) and photographed by [`tools/screenshots.mjs`](../../tools/screenshots.mjs), which rewrites each page's DOM and re-scans it before capturing. Every account, payee, amount and transaction shown is invented. The demo login's email and the host name were the only strings the tool had to rewrite.

The intro-tour popup Firefly shows on first visit is dismissed by the tool before the capture.
